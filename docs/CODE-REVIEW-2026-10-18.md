## Замечания

### 1. [P2] ARM64 ZIP не получает Servo при сборке `dist-arm64-servo`

Место: [Makefile](../Makefile#L203).

Зависимость `dist-arm64` сначала создаёт `dist/zimlite-linux-arm64.zip`.
Затем `dist-arm64-servo` копирует runtime в `dist/zimlite/servo`, но ZIP
не пересоздаёт. В каталоге есть Servo, а архив, предназначенный для
распространения, по-прежнему содержит обычную сборку. После его распаковки
полный renderer недоступен и приложение переходит на SDL.

Проверка: оригинальный рецепт цели выполнен во временном каталоге с
минимальными файлами приложения и runtime. После выполнения каталог содержал
`servo/run.sh`, а ZIP содержал только исходный файл приложения. Docker
в этой проверке не запускался.

Исправление: создавать итоговый ZIP после добавления runtime, либо явно
выделить отдельный архив Servo и указывать его как результат этой цели.

### 2. [P2] Восстановление выбранной ссылки сбивает сохранённую прокрутку Servo

Места: [ui.go](../internal/ui/ui.go#L114),
[session.rs](../native/servo-host/src/session.rs#L571).

`restoreView` сначала посылает сохранённый `scroll_to`, затем `select`.
Обработчик `select` всегда вызывает `zimliteSelectLink(index, true)`, а
`true` включает `scrollIntoView`. Если пользователь выбрал ссылку и затем
прокрутил статью так, что ссылка ушла за экран, возврат из настроек, дерева
или поиска переносит его обратно к ссылке. В SDL установка индекса сама
по себе не прокручивает страницу.

Проверка: JavaScript, извлечённый из текущего Rust-исходника, выполнен в Node
с минимальной моделью DOM. После восстановления прокрутки 1000 команда
`select` изменила её на 100 — положение выбранной ссылки.

Исправление: восстанавливать выделение без раскрытия ссылки; прокрутку к
ссылке выполнять при явной навигации пользователя.

### 3. [P2] Крестовина не продолжает навигацию Servo на экране без ссылок

Место: [session.rs](../native/servo-host/src/session.rs#L584).

Когда выбранная ссылка находится за экраном, `move_link` ищет только
видимые ссылки. Если текущий экран занят большим изображением или текстом
без ссылок, цикл заканчивается `return`. Последующие нажатия стрелок и
крестовины повторяют этот же путь: ни выделение, ни прокрутка не меняются,
хотя ниже или выше есть другие ссылки. SDL в такой ситуации умеет выбрать
ближайшую ссылку за пределами экрана.

Проверка: исходный JavaScript выполнен в Node с выбранной ссылкой выше
экрана и следующей ниже экрана. `move_link` оставил индекс и прокрутку
неизменными.

Исправление: после неуспешного поиска видимых ссылок выбирать ближайшую
доступную ссылку в направлении движения и показывать её.

### 4. [P2] RTL неправильно определяет направление абзацев с числами

Место: [bidi.go](../internal/renderer/bidi.go#L25).

`paragraphIsRTL` считает первую цифру основанием для LTR. Поэтому строка
`2026 عام جديد` получает LTR вместо RTL. Кроме того, `visualWordOrder`
считает числа сильными буквенными последовательностями: для `عام 10 20`
он выдаёт порядок слов `[2 3 4 1 0]`, тогда как локальный FriBidi даёт
`[4 3 2 1 0]`. Исправленное отображение простого арабского текста ещё
не означает правильную обработку смешанного текста и чисел.

Проверка: две временные Go-проверки вызвали непосредственно функции
текущего renderer и воспроизвели обе ошибки. Эталонный порядок получен
локальным вызовом `fribidi_log2vis`. Временный тестовый файл удалён.

Исправление: определять направление по bidi-классам сильных символов и
использовать полноценное разрешение уровней bidi для абзаца/строки.

### 5. [P2] Обязательный линтер не проходит

Место: [draw.go](../internal/renderer/draw.go#L543).

`make lint` сообщает две ошибки `errcheck`: не проверяются результаты
`shapedTex.SetColorMod` и `shapedTex.SetAlphaMod`. Это ошибки текущих
незакоммиченных изменений. Требуется обработать ошибки с освобождением
текстуры и корректным продолжением отрисовки.
