Helper swap was zero at both stops. System reserve was 194.9 MiB. Thus the
trigger was the separate dynamic helper budget, not crossing the system reserve
or a kernel OOM kill of Servo. The current formula allocates two thirds of
`MemAvailable + helperRSS - reserve`, with additional fixed caps.

The second session received commands and produced 6–9 FPS in several intervals
before stopping, with 63–109 ms average paint times. Aggregate command/frame
counts cannot prove that the article's scroll position changed: the profile does
not record command types/deltas alongside before/after scrollY. Therefore this
log establishes why full rendering was interrupted, but not why a specific stick
movement might have left the image unchanged before fallback.

On the second opening, fallback was ready at 10:22:12.400, around 2.14 seconds
after interruption. Parsing took 314 ms; source HTML was reused from memory.

## Improvements implemented after this investigation

At the user's request, the fractional allowance and fixed helper RSS caps were
removed. Physical allowance is now `MemAvailable + helperRSS - 50 MiB`, with
swap excluded from capacity. The system reserve and short growth forecast
remain; swap checks require low physical headroom. Main-process swap and raw
CMA diagnostics are logged. Cleanup waits for ownership release for up to
100 ms after process exit, so ordinary cleanup cannot cause the observed race.
Scroll extent/position and frame sequence are logged, including when no frames
are produced; native summaries distinguish applied vertical and table deltas.

helper at 640×351/motion scale 1. Results:

## Horizontal table targeting follow-up

The subsequent device log `/tmp/zimlite-profile.AADpJd` (copied locally to
`/tmp/zimlite-horizontal-before`) contains state samples with `selected_link=-1`,
zero table dimensions and native summaries with `table_commands=0`. The previous
implementation only targeted a table containing the selected link, and the SDL
adapter rejected horizontal input using that asynchronous state. Tables without
selected links therefore could not scroll.

The helper now resolves a visible wide table for both state and commands: a
visible selected link's table has priority, otherwise the table nearest the
viewport centre is chosen. Offscreen tables cannot receive this input. The SDL
adapter forwards horizontal motion without waiting for table state. The page
root never receives horizontal input.
